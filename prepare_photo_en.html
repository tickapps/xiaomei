Prepare and check your ID photo

Confirm the application rules before choosing a preset or editing a photo.

  1. Find the requirements.Use the current instructions for your application. Note the dimensions, background, format and file-size limits. Print dimensions and pixel dimensions are different.
  2. Check the preset.Choose the relevant document or use custom dimensions. Compare the values with the instructions.
  3. Take or upload a photo.Follow the authority’s instructions for lighting and framing, and check that the image is clear.
  4. Check editing restrictions.The app offers background removal and adjustable retouching. Do not use edits prohibited by your application rules.
  5. Inspect the export.HD export is free after watching an ad. Check the actual file before submission; HD export does not automatically meet file-size limits.
Check the application rules before submitting

A size preset does not establish that a photo meets every application rule. Check the current requirements for the background, framing, file size and editing. Some applications do not allow retouching, AI changes or background replacement; check before using these features.

Why the right size is not enough
