## 本轮范围

中英文入口与导航、合规措辞、隐私入口、尺寸用途目录框架与搜索、制作检查及打印指南、robots和sitemap。复用既有截图并标注真实功能，未改写隐私政策，未安装统计或提交收录。既有?lang=en链接保留显式跳转；根地址不再按JS默认跳转。

尺寸JSON由App开发维护。当前目录只有经产品资料确认的用途分类，不发布待修复的具体参数，不标注官方认证，不统计未核验的规格总数。待开发给出修正数据和对应平台版本后再接入详细目录。新增条目需有稳定ID、名称、分类、单位、参数、来源、核验状态；同名不同值不得自动合并。

## 发布前后

1. 预览审查中英文页面和导航。
2. 确认robots的GPTBot训练策略；本稿采用项目默认拒绝训练、允许搜索。
3. 获得生产发布授权后合并；检查线上状态、canonical、hreflang、图片、站点地图和真实爬虫访问。

5. 分别测量AI提及、引用和商店点击；不把网页搜索结果当作AI推荐。
