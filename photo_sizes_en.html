Passport, visa and ID photo size presets

Search by country or document to find a photo size preset. This catalogue uses the developer’s updated preset data supplied on October 28, 2026. Available options can vary by region, platform and app version. Custom dimensions are also supported.

Updated October 29, 2026. These are app preset values, rather than certification by a receiving authority.

Check the application rules before submitting

A size preset does not establish that a photo meets every application rule. Check the current requirements for the background, framing, file size and editing. Some applications do not allow retouching, AI changes or background replacement; check before using these features.

Dimensions are width × height. mm means millimetres, in means inches (1 inch = 25.4 mm), and px means pixels. DPI is the resolution declared in the preset data. Digital submissions also have file-format, file-size and framing requirements.
